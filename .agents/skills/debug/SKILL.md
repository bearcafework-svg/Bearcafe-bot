# Unified Debug & Diagnostic Skill (`/debug`)

Use this skill to investigate and resolve issues:
1. **Log & Trace Analysis**: Extract stack traces, identify failure points.
2. **Root Cause Analysis**: Trace code paths (Discord Bot, Database, Web Dashboard).
3. **Minimal Safe Patch**: Apply surgical fix following clean architecture.
4. **Verification**: Confirm fix resolves error without regressions.
