# 🐝 เอกสารออกแบบและโครงสร้างระบบผึ้ง (Bee Character & Behavior System Spec)

เอกสารนี้รวบรวม **คู่มือการออกแบบผึ้ง**, **กลไกพฤติกรรมเกม (Mechanics Matrix)**, **ตารางสถานะของผึ้งทั้ง 5 ตัว (Game State Matrix)**, และ **แบบฟอร์มสำหรับเพิ่มผึ้งตัวใหม่** ในบอทคาเฟ่หมี

---

## 🌟 1. รายชื่อและข้อมูลผึ้งหลักทั้ง 5 ตัว (The 5 Core Bees)

### 1. เจ้าผึ้งอ้วน (`fat_round_bee`)
- **แนวคิด (Concept):** Standard Rush — ผึ้งฝึกหัดตัวแรก เล่นง่าย ลุ้นสนุก 50/50
- **อัตราการชนะ (Win Rate):** 50%
- **แต้มชนะ:** +15 ถึง +50 แต้ม
- **แต้มแพ้:** -15 ถึง -50 แต้ม (หากแต้มติดลบโดนพิษ -150 แต้ม)
- **ระบบปุ่ม:** รอหน่วงเวลา 6 วินาที (Waiting) จึงจะเปลี่ยนเป็นปุ่มเขียวแย่งกด (Ready)
- **สถานะทั้งหมด (States):**
  1. `Spawn (Waiting)`: ปุ่มเทา ปิดการกด ชะลอให้ผู้เล่นเตรียมตัว
  2. `Spawn (Ready)`: ปุ่มเขียว เปิดให้แย่งกดชิงสตรอว์เบอร์รี
  3. `Win`: ขโมยสตรอว์เบอร์รีสำเร็จ
  4. `Loss`: โดนต่อยแต้มลด
  5. `Poison`: แต้มไม่พอ โดนพิษเหล็กในเต็มแรง
  6. `Expired`: ไม่มีใครกดใน 15 นาที บินหนีกลับรัง

---

### 2. นางพญาผึ้ง (`queen_bee`)
- **แนวคิด (Concept):** High Risk High Return + Jackpot — รางวัลมหาศาล และมีโอกาสขโมยมงกุฎแจ็กพอต
- **อัตราการชนะ (Win Rate):** 60%
- **โอกาสแจ็กพอต (Jackpot Chance):** 5% ของการชนะ (เมื่อทอยเต๋าได้ <= 0.05)
- **แต้มชนะปกติ:** +100 ถึง +300 แต้ม
- **แต้มแจ็กพอตมงกุฎ:** +1,500 ถึง +2,500 แต้ม!
- **แต้มแพ้:** -100 ถึง -200 แต้ม (ติดพิษ -250 แต้ม)
- **สถานะพิเศษ:**
  - `Bankrupt (แต้มหมดตัว)`: กรณีแต้มไม่พอจ่าย แต่ยังมากกว่า 0 จะถูกรีเซ็ตแต้มเหลือ 0
- **สถานะทั้งหมด (States):**
  1. `Spawn (Ready)`: นางพญาสง่างามพร้อมแจกและลงโทษ
  2. `Win Normal`: ขโมยสตรอว์เบอร์รีสำเร็จ
  3. `Win Crown Jackpot`: ขโมยมงกุฎทองคำสำเร็จ (+1,500~2,500 แต้ม)
  4. `Loss`: โดนเหล็กในหลวงราชินีต่อย
  5. `Bankrupt`: โดนยึดสตรอว์เบอร์รีจนหมดเกลี้ยงสวน
  6. `Poison`: ไม่มีแต้มให้ยึด โดนพิษพระราชทาน
  7. `Expired`: บินหนีกลับพระราชวัง

### 3. เจ้าผึ้งแวมไพร์ (`vampire_bee`)
- **แนวคิด (Concept):** Target Stealing & Awakening — ผึ้งสองจังหวะ คนแรกโดนกัดเพื่อปลุก จากนั้นมีเวลา 60 วินาทีให้แท็กเพื่อนเพื่อดูดแต้ม
- **อัตราการโดนดูดตัวเอง (Drain Self):** 80%
- **แต้มโดนดูดเอง:** เสีย -30 ถึง -80 แต้ม
- **แต้มดูดเพื่อนสำเร็จ:** ขโมยจากเพื่อนมาให้ตัวเอง +50 ถึง +120 แต้ม
- **หน้าต่างการแท็ก (Awaken Window):** 60 วินาที นับถอยหลังด้วย `<t:${timestamp}:R>`
- **ระบบป้องกัน (Edge Cases):**
  - แอบดูดบอท (Drain Bot): โดนผึ้งงง ไม่ได้แต้ม
  - เพื่อนแต้มหมด (Drain Poor): เพื่อนไม่มีแต้มให้ดูด
  - ดูดเจ้าของสวน/แอดมิน (Drain Owner): บารมีปกป้อง ไม่เสียแต้ม
- **สถานะทั้งหมด (States):**
  1. `Spawn (Sleepy)`: ผึ้งหลับปุ๋ย บินสะลึมสะลือ
  2. `Drain Self`: ผู้เล่นคนแรกกดปลุกแล้วโดนดูดพลังตัวเอง
  3. `Awaken Phase`: ผึ้งตื่นขึ้นมา ตาเปล่งแสงสีแดง ให้เวลา 60 วินาทีในการแท็กเพื่อน
  4. `Drain Friend Success`: ดูดแต้มเพื่อนสำเร็จ
  5. `Drain Bot / Drain Fail`: ข้อความเตือนเมื่อแท็กบอทหรือเป้าหมายผิดเงื่อนไข

### 4. เจ้าผึ้งสายลับ (`spy_bee`)
- **แนวคิด (Concept):** 3-Star Lucky Gacha — ผึ้งลูกผสมหมูสายลับ 3 ดาว มี 3 ปุ่มแว่นดำให้สุ่มการ์ด
- **ระบบปุ่ม:** 3 ปุ่มสไตล์ 1 (Primary Blurple) แสดงผลเฉพาะ Emoji แว่นดำ ไม่มีตัวหนังสือ
- **ผลลัพธ์การสุ่มการ์ด (Star Cards):**
  - `+Point`: รับแต้มสตรอว์เบอร์รีฟรี (+20 ถึง +60 แต้ม)
  - `-Point`: โดนหมูสายลับกินสตรอว์เบอร์รี (-15 ถึง -40 แต้ม)
  - `Meme Card`: มีมกวนๆ สุ่มภาพ 3 แบบ (สายลับเก็กหล่อ, กินแตงโม, โดนจับได้)
  - `Quest Card (Baby Carrot Role)`: ได้รับยศพิเศษ Baby Carrot (หากมียศอยู่แล้ว จะเปลี่ยนเป็นมอบแต้ม +100 แต้มแทน)
- **สถานะหมดดาว (All Stars Gone):** เมื่อผู้เล่นกดครบทั้ง 3 ดาวแล้ว ผึ้งจะบินหายไป
- **สถานะทั้งหมด (States):**
  1. `Spawn (3 Stars)`: หมูสายลับบินส่องพร้อม 3 ดาวนำโชค
  2. `Result (+Point)`: ได้แต้มบวก
  3. `Result (-Point)`: โดนกินแต้ม
  4. `Result (Meme Card)`: สุ่มได้การ์ดมีมสุดปั่น
  5. `Result (Role Quest)`: ได้รับยศ Baby Carrot หรือแต้มชดเชย
  6. `All Stars Depleted`: ดาวหมดเกลี้ยง บินหลบหนี

---

### 5. อาจารย์บีเรขา (`math_bee`)
- **แนวคิด (Concept):** Speed Math Quiz — ผึ้งอาจารย์ปล่อยโจทย์คณิตคิดเร็ว 3 ช้อยส์ ใครตอบถูกคนแรกชนะ
- **ระดับความยาก (Difficulty Tiers):** สุ่ม 3 ระดับ
  - Tier 1 (อนุบาลหมี): บวกเลขง่ายๆ ไม่เกิน 50
  - Tier 2 (ประถมหมี): คูณเลขสองหลัก หรือบวกลบผสม
  - Tier 3 (มัธยมหมี): สมการคูณและลบ 3 ขั้นตอน
- **ระบบปุ่ม:** 3 ปุ่มสไตล์หลากสี (Style 1 น้ำเงิน, Style 3 เขียว, Style 4 แดง) แสดงตัวเลขคำตอบเท่านั้น ไม่มี Emoji
- **บทลงโทษตอบผิด:** ติดคูลดาวน์ห้ามกดตอบ 7 วินาที
- **รางวัลตอบถูก:** ได้รับ +30 ถึง +90 แต้มสตรอว์เบอร์รี (ข้อความแสดงผลสะอาด ไร้สตรอว์เบอร์รีซ้ำซ้อน)
- **สถานะทั้งหมด (States):**
  1. `Spawn`: บทพูดไม้ชี้กระดาน + สุ่มโจทย์เลข 3 ช้อยส์
  2. `Win`: ผู้เล่นตอบถูกคนแรก รับเกียรตินิยมและแต้ม
  3. `Wrong Answer (Cooldown)`: ตอบผิด ติดดีเลย์ 7 วินาที
