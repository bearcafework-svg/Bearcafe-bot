---
description: วางแผน ออกแบบสถาปัตยกรรม และวิเคราะห์เปรียบเทียบทางเลือกก่อนเริ่มแตะต้องโค้ด (Architecture Planning & Consultation)
---

- วิเคราะห์ความต้องการเชิงลึก: ตั้งข้อสังเกต สำรวจโค้ดจริง และถามคำถามชี้ขาดในจุดที่คลุมเครือ
- เปรียบเทียบทางเลือก (Trade-off Matrix): ชั่งน้ำหนักข้อดี-ข้อเสีย (เช่น In-Memory Cache vs Redis vs Supabase Table)
- ประเมินความเสี่ยงและทรัพยากร: วิเคราะห์ผลกระทบต่อโควตา Supabase Egress และ Discord API Rate Limits
- สร้าง Implementation Plan: สรุปรายการไฟล์ที่จะต้องสร้าง/แก้ไข, ขั้นตอนการพัฒนาแบบเป็นลำดับ, และแผนการทดสอบ (Verification Strategy)
- เมื่อไหร่ควรใช้: เริ่มพัฒนาฟีเจอร์ใหม่, ปรับแก้ระบบโครงสร้างใหญ่, หรือเมื่อโจทย์ยังมีความไม่ชัดเจน
