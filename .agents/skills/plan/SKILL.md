# Implementation Planning Skill (`/plan`)

Use this skill before writing code on complex features:
1. **Discovery & Inspection**: Scan existing codebase, tables, and patterns.
2. **Dependency & Blast Radius**: Trace affected components across Bot and Web.
3. **Step-by-Step Execution Plan**: Design clean 3-tier implementation.
4. **Verification Strategy**: Outline testing criteria and risk mitigations.
