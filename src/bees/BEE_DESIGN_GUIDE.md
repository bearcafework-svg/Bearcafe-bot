# 🐝 เอกสารออกแบบและสร้างผึ้งตัวใหม่ (Bee Character & Behavior Creator Spec)

เอกสารนี้ใช้สำหรับ **ออกแบบผึ้งตัวใหม่** ในระบบของคาเฟ่หมี โดยแบ่งออกเป็น:
1. **แบบฟอร์มกรอกข้อมูลผึ้ง (แบบพร้อมกรอก)**
2. **คลังพฤติกรรมและกลไกเกม (Behavior & Mechanics Matrix)**
3. **แนวทางการเขียนบทพูดให้มีชีวิตชีวา (Dialogue Guidelines)**
4. **โค้ด JSON & Component v2 Payload สำหรับนำไปใช้งานจริง**

---

## 📝 1. แบบฟอร์มกรอกข้อมูลผึ้งตัวใหม่ (Bee Profile Form)

> 💡 **วิธีใช้:** คัดลอกส่วนนี้ไปกรอกข้อมูลเมื่อต้องการสร้างผึ้งตัวใหม่ จากนั้นส่งให้ AI นำไปแปลงเป็นโค้ดในระบบได้ทันที

```markdown
### 🐝 ข้อมูลทั่วไป (General Info)
- **ชื่อผึ้ง**: (เช่น เจ้าผึ้งขี้งอน / เจ้าผึ้งนักกล้าม / เจ้าผึ้งจอมตระกละ)
- **ID (ภาษาอังกฤษตัวพิมพ์เล็ก)**: (เช่น pouty_bee / muscle_bee / greedy_bee)
- **บุคลิก / นิสัย (Personality)**: (เช่น ขี้งอน ขี้น้อยใจ ชอบให้คนมาเอาใจ / บ้าพลัง ชอบท้าประลอง)
- **ระดับความหายาก / น้ำหนักการสุ่ม (Spawn Weight)**: (ค่าปกติ 1, หายาก 0.5, บ่อย 2)
- **เปิดใช้งานทันทีหรือไม่**: [x] เปิด (true) / [ ] ปิด (false)

### 🎮 พฤติกรรมและเงื่อนไขเกมเพลย์ (Behavior & Mechanics)
- **รูปแบบปุ่มกด (Button Style)**:
  - [ ] แย่งกดปุ่มเดียวปกติ (First-come, first-served)
  - [ ] ปุ่ม 2 ทางเลือก (เสี่ยงทายซ้าย/ขวา)
  - [ ] ปุ่มตอบคำถามมินิเกม (Select Menu / Q&A)
  - [ ] ปุ่มท้าประลอง / กดซ้ำทำคะแนน
- **เวลารอปลดล็อกปุ่ม (Button Delay)**: 5000 ms (5 วินาที)
- **อัตราการชนะ (Win Rate)**: (เช่น 0.5 = 50%, 0.7 = 70%)
- **แต้มสตรอว์เบอร์รีที่ได้รับเมื่อชนะ**: ขั้นต่ำ ___ ถึง สูงสุด ___ แต้ม
- **แต้มสตรอว์เบอร์รีที่เสียเมื่อแพ้**: ขั้นต่ำ ___ ถึง สูงสุด ___ แต้ม
- **แต้มที่เสียกรณีแต้ม <= 0 (ติดพิษ Poison)**: ___ แต้ม (ค่ามาตรฐาน -150)
- **พฤติกรรมพิเศษ (ถ้ามี)**: (เช่น ถ้ากดผิดปุ่มจะโดนหักแต้มเบิ้ล 2 เท่า)

### 💬 บทพูดเจ้าผึ้ง (Character Dialogues)
- **ตอนบินโผล่มาในสวน (Spawn)**:
  > "(พิมพ์บทพูดตอนบินโผล่มา เช่น แถวนี้มีสตรอว์เบอร์รีไหมนะ! ถ้าไม่มีจะงอนแล้วนะ!)"
- **ตอนผู้เล่นชนะ / แย่งแต้มได้ (Win)**:
  > "(พิมพ์บทพูดตอนโดนผู้เล่นแย่ง เช่น แง้! โดนแย่งไปแล้ว! นิสัยไม่ดีเลยนะเจ้าหมี!)"
- **ตอนผู้เล่นแพ้ / ผึ้งต่อยขโมยแต้ม (Loss)**:
  > "(พิมพ์บทพูดตอนต่อยชนะ เช่น ฮ่าๆๆ สตรอว์เบอร์รีนี่เสร็จฉันล่ะ! อย่าหวังจะได้คืน!)"
- **ตอนผู้เล่นแต้ม <= 0 โดนพิษต่อยซ้ำ (Poison Loss)**:
  > "(พิมพ์บทพูดตอนซ้ำเติมคนไม่มีแต้ม เช่น ไม่มีแต้มให้ฉันเหรอ!? งั้นรับเหล็กในพิษไปแทนซะ!)"
- **ตอนไม่มีใครกดภายใน 15 นาที / บินหนี (Expired)**:
  > "(พิมพ์บทพูดตอนหนีกลับรัง เช่น ไม่มีใครสนใจเลย ชิ! กลับรังไปหาแม่ดีกว่า!)"

### 🖼️ ลิงก์รูปภาพ (Asset URLs)
- **รูปตอนโผล่ (Spawn Image)**: https://...
- **รูปตอนชนะ (Win Image)**: https://...
- **รูปตอนต่อยแพ้ (Lose Image)**: https://...
- **รูปตอนติดพิษ (Poison Image)**: https://...
- **รูปตอนบินหนี (Expire Image)**: https://...
```

## 🎯 2. คลังแนวคิดพฤติกรรมผึ้ง (Behavior Matrix)

คุณสามารถเลือกรูปแบบพฤติกรรมเพื่อสร้างความสนุกและแปลกใหม่ให้กับผึ้งแต่ละตัว:

| รูปแบบพฤติกรรม | ลักษณะการเล่น | ตัวอย่างผึ้งที่เหมาะ | การให้ผลรางวัล / บทลงโทษ |
| :--- | :--- | :--- | :--- |
| **1. Standard Rush (มาตรฐาน)** | ปุ่มเดียว รอ 5 วิแล้วแย่งกด คนแรกได้ลุ้น 50/50 | `fat_round_bee` (เจ้าผึ้งอ้วน) | ได้แต้มปกติ (+15~50) / เสียปกติ (-15~50) |
| **2. High Risk High Return** | ผึ้งสายเปย์ แต้มเยอะมาก แต่ถ้าแพ้จะโดนหักหนัก | `queen_bee` (นางพญาผึ้ง) | ชนะได้ (+100~300) / แพ้เสีย (-100~200) |
| **3. Fast Reflex (ความเร็วสูง)** | ปุ่มเปิดเร็วมาก (รอแค่ 1-2 วินาที) ต้องตาไว | `ninja_bee` (ผึ้งนินจา) | ชนะได้ (+30~80) / แพ้เสีย (-20~40) |
| **4. Lucky Choice (เสี่ยงดวง 2 ทาง)** | มีปุ่ม 2 ปุ่ม "ดอกไม้สีแดง" หรือ "ดอกไม้สีฟ้า" | `clover_bee` (ผึ้งสี่แฉก) | เลือกถูกได้แต้ม / เลือกผิดโดนต่อย |
| **5. Gentle Bee (ผึ้งใจดี)** | ไม่เคยต่อยใคร โอกาสชนะ 100% แต่แจกแต้มน้อย | `angel_bee` (ผึ้งนางฟ้า) | ได้แต้มแน่นอน (+10~30) ไม่มีติดพิษ |
| **6. Berserk Bee (ผึ้งหัวร้อน)** | โอกาสชนะต่ำมาก (20%) ต่อยหนักเป็นพิเศษ | `angry_bee` (ผึ้งพิโรธ) | ชนะได้ (+80) / แพ้เสีย (-80) ติดพิษ (-250) |

## 🎭 3. ตัวอย่างการออกแบบผึ้งสำเร็จรูป (Pre-designed Examples)

### ตัวอย่างที่ 1: เจ้าผึ้งขี้แย (Crying Bee)
- **ID**: `crying_bee`
- **บุคลิก**: อ่อนไหว ขี้ตกใจ ร้องไห้ง่ายเวลาเจอคน
- **สถิติ**: Win Rate 70% (ชนะง่าย) | แต้มชนะ +20~40 | แต้มแพ้ -10~25 | พิษ -100
- **บทพูด**:
  - **Spawn**: `(บินตัวสั่น) มะ...มีใครอยู่แถวนี้ไหม ฮือออ อย่าแกล้งหนูนะ!`
  - **Win**: `(ร้องไห้โฮ) แงงง! เอาสตรอว์เบอร์รีหนูคืนมานะ คนใจร้ายยย!`
  - **Loss**: `(ปาดน้ำตาแล้วต่อย) ฮึก... หนูป้องกันตัวเฉยๆ นะ! อย่าตามมานะ!`
  - **Poison**: `(ตกใจ) อ้าว... ไม่มีสตรอว์เบอร์รีเลยเหรอ... งั้นหนูแถมเหล็กในให้แก้หนาวนะ!`
  - **Expired**: `(บินหนีเงียบๆ) ไม่มีใครอยู่จริงๆ ด้วย... ปลอดภัยแล้วเรา ฟิ้ว~`

---

### ตัวอย่างที่ 2: เจ้าผึ้งสายเปย์ (Rich Honey Bee)
- **ID**: `rich_bee`
- **บุคลิก**: สวมแว่นดำ ถือถุงทอง หยิ่งในความรวย ชอบแจกแต่ถ้ากวนใจจะสั่งสอน
- **สถิติ**: Win Rate 40% (ชนะยากหน่อย) | แต้มชนะ +80~150 | แต้มแพ้ -60~100 | พิษ -200
- **บทพูด**:
  - **Spawn**: `(ดีดนิ้ว) สวนนี้ราคาเท่าไหร่? ฉันเหมาหมด! ใครอยากได้เศษเงินก็เข้ามา!`
  - **Win**: `(โยนเหรียญ) เหอะ! ถือว่าทำบุญให้เจ้าหมีผู้หิวโหยละกันนะ!`
  - **Loss**: `(เอาถุงเงินฟาด) คิดจะมาปล้นเสี่ยเหรอ!? ไปฝึกมาใหม่ไป๊ไอ้หนู!`
  - **Poison**: `(มองเหยียด) หืม? แต้มติดลบยังกล้ามาแหยม? ปรับทัศนคติสัก 200 แต้มไปซะ!`
  - **Expired**: `(ดูนาฬิกาหรู) เสียเวลาทำธุรกิจจริงๆ พวกหมีที่นี่จนแถมยังชักช้า บาย!`

> [!TIP]
> **ระบบเทมเพลตบินหนีกลับรัง (Expired Template):**

## 🎨 5. โครงสร้าง Component v2 Template (นำไปใส่ใน `beePayloads.js`)

```javascript
// ตัวอย่างการประกอบ Payload Component v2 ตามบทพูดของผึ้งที่ออกแบบ
function buildCustomBeeSpawnPayload(beeConfig, customId, isReady = false) {
  const dialogue = beeConfig.dialogues?.spawn || "(บินวนไปมาในสวน)";

  return {
    flags: 32768, // MessageFlags.IsComponentsV2
    components: [
      {
        type: 17, // Container
        components: [
          { type: 14, divider: false },
          {
            type: 9, // Section
            components: [
              {
                type: 10, // Text Display
                content:
                  `## <:bee20000:1256669436350562355>︲__\` 𝖡𝖾𝖾 ₊ ${beeConfig.name} 𓂃 \`__\n` +
                  `-# <a:3602exclamationmarkbubble:1372837492205555812>⠀**บทพูดเจ้าผึ้ง** : ${dialogue} <:cuteplant:1152834055528783872>\n` +
                  ` > (<:strawberryv2:1520439075100688614>)⠀**__\`𝗍𝗂𝗉𝗌\`__** : สะสมสตรอว์เบอร์รีให้ได้มากที่สุด!`
              }
            ],
            accessory: {
              type: 11, // Thumbnail Icon
              media: { url: beeConfig.spawn_image_url }
            }
          },
          { type: 14, divider: false, spacing: 2 },
          {
            type: 12, // Media Gallery (Background)
            items: [{ media: { url: beeConfig.garden_background_url } }]
          },
          { type: 14, divider: true, spacing: 2 },
          {
            type: 1, // ActionRow
            components: [
              {
                type: 2,
                style: isReady ? 3 : 1,
                label: isReady ? "︲คลิกฉันสิ! คลิกฉันสิ!" : "︲กำลังโหลดผึ้ง . . .",
                custom_id: customId,
                disabled: !isReady
              }
            ]
          }
        ]
      }
    ]
  };
}
```
